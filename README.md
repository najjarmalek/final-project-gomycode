## 🚀 About

**Tunisian Drift** is a static website created to promote and celebrate the drift culture in Tunisia. It serves as an information hub for drift enthusiasts and a simple e-commerce-style shop where visitors can browse and purchase drift equipment.

The project was built entirely with vanilla **HTML**, **CSS**, and **JavaScript** — no frameworks or back-end — making it lightweight, fast, and easy to host anywhere.

## 🖥️ Pages & Features

### 🏠 Home Page
- General information about **drifting in Tunisia**
- Introduction to the local drift scene, events, and community
- Hero section with engaging visuals
- Navigation to the shop and other sections

### 🛒 Shop
- Display of drift equipment (e.g., tires, helmets, steering wheels, suspension parts)
- Product cards with images, names, and prices
- Add-to-cart / cart functionality *(powered by JavaScript)*
- Clean product layout

### ✨ General Features
- 🎨 Modern and clean UI
- ⚡ Fast loading (no external dependencies)
- 🧭 Smooth navigation between pages
